# PSOC Edge Machine Learning DEEPCRAFT Deploy Ready Model

This repository contains the deployment-ready Edge Machine Learning models built for PSoC (Programmable System-on-Chip) microcontrollers, generated using DEEPCRAFT™ Studio.

## Overview

This project includes pre-trained and optimized machine learning models ready to be deployed on Infineon/Cypress PSoC edge devices. It is designed to demonstrate efficient AI/ML capabilities directly on the edge, minimizing latency and power consumption.

### Features
- **Edge AI Deployment:** Ready-to-deploy ML models for PSoC.
- **DEEPCRAFT™ Integration:** Generated and optimized using DEEPCRAFT™ tools.
- **Low Power & Low Latency:** Designed specifically for edge environments.

## Repository Structure

- `proj_cm33_s/`, `proj_cm33_ns/`, `proj_cm55/` - Project files for different ARM Cortex-M architectures.
- `images/` - Resource images.
- `docs/` - Documentation and setup guides.
- `shared/` - Shared libraries and headers.
- `Makefile` - Build scripts for compilation.

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/NaruesornK/PSOC_Edge_Machine_Learning_DEEPCRAFT_Deploy_Ready_Model.git
   ```
2. Open the project using ModusToolbox™ or your preferred IDE for PSoC.
3. Build the project using the provided Makefiles.
4. Flash the compiled firmware onto your PSoC board.
